This directory contains the curated benchmark artefacts referenced by the dissertation.

- environment_latest.txt: environment and tool metadata for the reported benchmark set
- raw_runs_latest.csv: per-run raw benchmark data
- trimmed_summary_latest.csv: trimmed aggregate summary used for analysis


Large transient server logs and local scratch outputs were omitted from the submission bundle.
The dissertation tables are derived from raw_runs_latest.csv and trimmed_summary_latest.csv.
